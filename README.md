# Calculator

A Phython 3 calculator used from the terminal, built step by step in SCCM4910.

## What it will do
Add, subtract, multiply and divide two numbers; display the result.

##How to run it
Run: run.sh
Enter the first number, operator (+ - * /), then second number.
The program prints Result: followed by the answer.

##How to stop it
Use Ctrl-C to stop the program from running.
